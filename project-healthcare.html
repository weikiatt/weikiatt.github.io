NCCS Capstone Project (ANCHOR Chatbot)

AI Engineer · Jan 2026 – Apr 2026

Local-first agentic reasoning system for natural-language clinical queries on OMOP CDM data

The Problem

Clinicians often need to extract critical research insights from complex healthcare databases like OMOP CDM, but doing so requires writing complex SQL queries—a specialized technical barrier. Furthermore, any automated clinical solution must strictly adhere to healthcare data privacy laws and clinical safety standards: patient data cannot leave secure hospital environments, and AI-generated outputs cannot be blindly trusted without auditability and strict schema conformance.

The Solution

I architected ANCHOR, an autonomous, local-first multi-agent system executing locally via Ollama within a strict 8 GB GPU VRAM footprint. ANCHOR translates natural language queries from clinicians into dynamic, schema-validated SQL queries and statistical computations over OMOP CDM data, ensuring zero patient data leakage with complete reasoning transparency.

Key Architectural Highlights & Outcomes

  • Local 8-Agent LangGraph Workflow: Architected an 8-agent LangGraph workflow executing locally via Ollama within an 8 GB GPU VRAM footprint, orchestrating DeepSeek-R1 (clinical reasoning) and Qwen2.5-Coder (SQL/statistical execution).
  • Dynamic VRAM Management & LRU Caching: Implemented dynamic model VRAM management (keep_alive lifecycle) and a Data Registry LRU cache using serialized data reference keys to prevent inter-node memory exhaustion during analytical execution.
  • Hybrid Concept-Resolution Engine: Built a hybrid concept-resolution engine combining Bio_ClinicalBERT and FAISS, incorporating dataset-level fallbacks to eliminate OMOP Concept ID hallucinations in generated SQL queries.
  • Autonomous Self-Correcting SQL Pipeline: Designed an autonomous DuckDB SQL generation pipeline featuring dynamic YAML schema pruning, column-resolution gating, and a 4-retry self-correction loop fed with live query execution traces.
  • Deterministic Statistical Verification & HITL: Engineered a deterministic statistical layer executing verified SciPy and lifelines routines (Kaplan-Meier survival curves, Cox regression, chi-squared tests) with a human-in-the-loop clarification gate for ambiguous clinical definitions.
