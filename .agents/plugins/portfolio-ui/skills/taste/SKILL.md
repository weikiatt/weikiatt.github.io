# Taste: Modern High-Converting Landing Pages & Portfolios

Use this skill when designing landing page sections, portfolio heroes, showcase grids, and calls-to-action that immediately communicate taste, credibility, and technical distinction.

---

## 1. Aesthetic Restraint: The Rules of Good Taste

- **Subtlety Over Sensation**:
  - Never use raw default colors (e.g. pure `#ff0000` or `#0000ff`). Use curated, nuanced HSL/Hex values (e.g. `#38bdf8`, `#6366f1`).
  - Gradients should be soft and ambient (e.g. 5–15% opacity radial glows), never harsh 100% linear rainbow blends.
- **Glassmorphism With Purpose**:
  - Pair subtle backdrop blur (`backdrop-filter: blur(12px)`) with semi-transparent surfaces (`rgba(15, 23, 42, 0.75)`) and delicate 1px border highlights (`rgba(255, 255, 255, 0.08)`).
- **Typography as Interface**:
  - Rely on strong typographic contrast: Heavy display headers (weight 700–800) paired with airy, well-tracked labels (`letter-spacing: 0.05em; text-transform: uppercase; font-size: 0.75rem;`).

## 3. High-Converting Showcase Card Patterns

- **Contextual Badges**: Tag each project with role + date + category right away (e.g. `AI Engineer · 2026`).
- **Quantifiable Outcome Snippet**: Never summarize just features; include the business or technical outcome (e.g., *"Achieved 8 GB VRAM execution with zero data leakage"*).
- **Clear Affordance Link**: Use explicit arrow links (*"Read Case Study →"*) that animate slightly on hover (`transform: translateX(4px)`).

---

## 4. Visual "Taste" Review Checklist
- [ ] No visual noise: Did you remove unnecessary container boxes, divider lines, and drop-shadow stacking?
- [ ] Atmospheric depth: Is there a soft background mesh or dark radial gradient grounding the page?
- [ ] Proof metrics prominently visible before the fold: Recruiter sees tangible impact numbers immediately.
- [ ] Micro-details: Refined border-radius consistency (e.g. 12px on cards, 8px on buttons, 9999px on pill tags).
